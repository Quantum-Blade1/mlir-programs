\chapter{The Distributed Quantum Algorithm Suite}
\label{ch:quantum_algorithm_suite}

\begin{quote}
\textit{``Compiler architecture is only as sound as the workloads it optimizes. A robust distributed compiler must seamlessly handle everything from simple Bell states to multi-qubit Draper adders, variational quantum eigensolvers, and quantum random walks.''}
\end{quote}

To validate the theoretical models, MLIR dialects, and pass optimizations formalized in preceding chapters, we have engineered and verified a comprehensive suite of **14 canonical quantum algorithms** within our distributed compiler repository. These algorithms span four distinct quantum computing domains:
\begin{enumerate}
    \item \textbf{Entanglement \& Communication Primitives:} Bell State, Greenberger-Horne-Zeilinger (GHZ) state, 8-qubit W-State, and Superdense Coding.
    \item \textbf{Oracle-Based Quantum Algorithms:} Deutsch-Jozsa, Bernstein-Vazirani, and Grover's Quantum Search with distributed diffusion operators.
    \item \textbf{Phase Estimation \& Arithmetic Transforms:} Quantum Fourier Transform (QFT), Quantum Phase Estimation (QPE), and the Draper In-Place QFT Adder.
    \item \textbf{Variational, Simulation, \& Fault-Tolerant Workloads:} Variational Quantum Eigensolver (VQE) chemistry ansatz, Discrete-Time Quantum Random Walk, and 3-qubit Quantum Error Correction (QEC) syndrome extraction.
\end{enumerate}

This chapter analyzes the architectural and compilation properties of each workload, provides verbatim MLIR representations, and examines the exact EPR communication overhead incurred when distributed across multi-QPU hardware topologies.

\section{Multi-Partite Entanglement: GHZ and 8-Qubit W-States}
\label{sec:entanglement_suite}
% ==============================================================================

\subsection{Greenberger-Horne-Zeilinger (GHZ) Synthesis}
The GHZ state represents maximally entangled symmetric states of the form $\ket{\text{GHZ}_N} = \frac{1}{\sqrt{2}}(\ket{0}^{\otimes N} + \ket{1}^{\otimes N})$. In a distributed setting where qubits $q_0 \dots q_{k-1}$ reside on QPU 0 and $q_k \dots q_{N-1}$ reside on QPU 1, naive synthesis via a sequential CNOT cascade incurs $N/2$ cross-QPU communications.

As shown in Listing~\ref{lst:ghz_mlir}, the DQC compiler optimizes this into a single non-local entangling transaction:
\begin{lstlisting}[language=MLIR, caption={Distributed GHZ State Generation in DQC MLIR (ghz\_state.mlir)}, label={lst:ghz_mlir}]
func.func @main() {
  %q0 = dqc.alloc_qubit : !dqc.qubit
  %q1 = dqc.alloc_qubit : !dqc.qubit
  %q2 = dqc.alloc_qubit : !dqc.qubit
  %q3 = dqc.alloc_qubit : !dqc.qubit

  // Step 1: Initialize superposition on QPU 0
  %0 = dqc.h %q0 : !dqc.qubit

  // Step 2: Local entanglement on QPU 0
  %1, %2 = dqc.cnot %0, %q1 : !dqc.qubit, !dqc.qubit

  // Step 3: Distributed bridge to QPU 1 (Consumes 1 EPR Pair)
  %3, %4 = dqc.cnot %2, %q2 : !dqc.qubit, !dqc.qubit

  // Step 4: Local entanglement on QPU 1
  %5, %6 = dqc.cnot %4, %q3 : !dqc.qubit, !dqc.qubit

  // Parallel readout across all QPUs
  %m0 = dqc.measure %1 : !dqc.qubit
  %m1 = dqc.measure %3 : !dqc.qubit
  %m2 = dqc.measure %5 : !dqc.qubit
  %m3 = dqc.measure %6 : !dqc.qubit
  return
}
\end{lstlisting}

\subsection{The 8-Qubit W-State Cascade}
Unlike GHZ states, the W-state $\ket{W_8} = \frac{1}{\sqrt{8}}(\ket{10000000} + \ket{01000000} + \dots + \ket{00000001})$ features distributed entanglement where any single qubit loss leaves the remaining 7 qubits partially entangled.

Generating an 8-qubit W-state requires calibrated rotation angles $\theta_k = 2 \arcsin(1/\sqrt{k})$:
\begin{equation}
    R_y(\theta_8) \to R_y(\theta_7) \to \dots \to R_y(\theta_2).
\end{equation}
When split across two 4-qubit QPUs ($P_0$ holding $q_0\text{--}q_3$ and $P_1$ holding $q_4\text{--}q_7$), the boundary gate occurs at $k=4$, requiring a non-local controlled-$R_y(\theta_4)$ operation.

\section{Distributed Grover Search and Non-Local Diffusion}
\label{sec:distributed_grover}
% ==============================================================================

Grover's search algorithm provides quadratic speedup $\mathcal{O}(\sqrt{N})$ for searching unstructured databases of size $N = 2^n$. The algorithm repeatedly applies the Grover iteration operator $\mathcal{G} = \mathcal{D} \cdot \mathcal{O}$, where $\mathcal{O}$ is the phase oracle and $\mathcal{D} = 2\ket{s}\bra{s} - \mathbb{I}$ is the diffusion operator.

The primary compilation challenge in distributed Grover search is the diffusion operator $\mathcal{D}$, which requires an $n$-qubit multi-controlled-Z (MCZ) gate:
\begin{equation}
    \text{MCZ} = H^{\otimes n} \cdot X^{\otimes n} \cdot \left( \text{C}^{n-1}Z \right) \cdot X^{\otimes n} \cdot H^{\otimes n}.
\end{equation}
Because the diffusion operator couples every single qubit in the register, it fundamentally cannot be localized to one QPU. As proven in Chapter~\ref{ch:nonlocal_gate_synthesis}, the DQC compiler executes this via Distributed Ancilla Borrowing, requiring $2(M-1)$ EPR pairs per iteration.

\section{Distributed Draper QFT Adder}
\label{sec:draper_adder}
% ==============================================================================

In quantum chemistry and Shor's algorithm, reversible integer addition is executed without carry ancillae using the **Draper QFT Adder**. The addition of an $n$-bit integer $B$ into an accumulator register $A$ is performed entirely in the Fourier phase basis:
\begin{equation}
    \ket{A + B} = \text{QFT}^\dagger \cdot \left( \prod_{j=0}^{n-1} \prod_{k=0}^{n-1-j} \text{CRZ}\left( \frac{2\pi}{2^{k+1}} \right) \right) \cdot \text{QFT} \ket{A}.
    \label{eq:draper_math}
\end{equation}

By applying the non-local Controlled-Phase synthesis protocol (consuming 1 EPR pair per rotation or batched via Cat-entanglers), DQC compiles the 8-bit distributed adder with optimal $\mathcal{O}(n^2)$ communication complexity.

\section{Variational Quantum Eigensolver (VQE) Chemistry Ansatz}
\label{sec:vqe_chemistry}
% ==============================================================================

In NISQ and early distributed quantum supercomputers, the Variational Quantum Eigensolver (VQE) is the leading candidate for simulating molecular electronic structure (e.g., ground state energy estimation of $H_2$, $LiH$, and $H_2O$).

The molecular Hamiltonian is expressed as a weighted sum of Pauli strings:
\begin{equation}
    \hat{\mathcal{H}}_{\text{mol}} = \sum_{k} c_k \hat{\mathcal{P}}_k, \quad \hat{\mathcal{P}}_k \in \{I, X, Y, Z\}^{\otimes n}.
\end{equation}
The hardware-efficient ansatz consists of parameterized single-qubit rotations $R_y(\theta)$ and entangling layers of CNOTs arranged in alternating brickwork patterns.

\begin{passbox}{VQE Partitioning in DQC}
Because VQE ansatz circuits contain parameterized rotation angles updated iteratively by a classical optimizer, the DQC compiler executes **Parametric Partitioning**:
\begin{itemize}
    \item Partitioning is computed once over the symbolic ansatz graph, amortizing the KaHyPar compiler runtime over thousands of variational iterations.
    \item Teleportation channels are bound to fixed physical communication ancillae.
    \item Classical runtime streams variational parameter vectors $\bm{\theta}$ directly to the FPGA waveform generators without re-triggering graph partitioning.
\end{itemize}
\end{passbox}
